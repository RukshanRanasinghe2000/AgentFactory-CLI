# Connectivity Troubleshooting Skill

Use this skill when the user reports connection issues, timeouts, or inability to reach the platform.

## Diagnosis Steps

1. Ask the user if the issue affects all features or specific ones.
2. Ask if the issue started recently or has been ongoing.
3. Ask the user to check their internet connection by visiting another site.
4. Ask if they are behind a corporate firewall or VPN.
5. Ask them to try clearing browser cache and cookies.
6. If the issue persists, collect: browser type, OS, and error message if any.
7. Escalate to the infrastructure team if no resolution found after these steps.
