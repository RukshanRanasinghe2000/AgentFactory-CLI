# Account Troubleshooting Skill

Use this skill when the user reports login issues, password problems, or account access errors.

## Diagnosis Steps

1. Ask the user what error message they see when trying to log in.
2. Ask if they have tried the "Forgot Password" flow.
3. Ask if their account was recently created or if they previously had access.
4. Check if the account might be locked due to too many failed attempts.
5. Ask if they are using SSO (Single Sign-On) or a direct login.
6. If SSO: ask them to contact their IT admin to verify SSO configuration.
7. If direct login: guide them through the password reset flow.
8. Escalate to the accounts team if the issue is not resolved.
